# The Godot Benchmark: GPT 5.6 Sol, Fable & Kimi 3

Three LLMs, one prompt, one-shot, inside the [Ziva](https://ziva.sh) Godot harness: build a 3D parkour world where you race bots across 3 courses using the Kenney Platformer Kit.

Each folder is the exact project the model produced (open in Godot 4.7, press Play). `TRANSCRIPT.md` is the full agent conversation.
